Authentication

Send a Firebase ID token from LUTUNG Google sign-in as a bearer token. There are no public API keys in this MVP; pilot developers request access from the LUTUNG team.{% if t.sensitive %} The account must also have acknowledged the current data-handling notice.{% endif %}

HeaderValue
AuthorizationBearer <Firebase ID token>required
Content-Typemultipart/form-datarequired

Example request

cURL
curl -X POST "https://<lutung-host>{{ t.docs.path }}" \
  -H "Authorization: Bearer $LUTUNG_ID_TOKEN" \
  -F "file=@image.jpg"

const form = new FormData();
