Error codes

Errors use a consistent shape. Every response carries an X-Request-Id header — include it when reporting issues.

Error response
{"request_id": "req_…", "error": {"code": "RATE_LIMITED", "message": "Too many requests. Please try again later."}}
CodeHTTPMeaning / what to do
INVALID_FILE400 · 411 · 415Unsupported, malformed or empty upload. Select a supported file and retry.
INVALID_REQUEST400A required field is missing or a number is outside the allowed range.
FILE_TOO_LARGE413Upload exceeds the size or dimension limit. Reduce file size.
UNAUTHORIZED401Missing, expired or invalid identity token. Sign in again.
CONSENT_REQUIRED403Data-handling notice must be acknowledged before using a sensitive-document service.
TRIAL_ALREADY_USED403Free trial consumed. Paid access is not available yet; contact the team for pilot access.
TRIAL_IN_PROGRESS409Another trial request for this account is processing. Wait for it to finish.
RATE_LIMITED429Request limit exceeded. Wait for the Retry-After interval.
SERVICE_UNAVAILABLE503Provider unavailable, busy, or under maintenance. Retry later; do not submit repeatedly.
PROCESSING_TIMEOUT504Processing exceeded the configured timeout. A trial is not consumed.
INTERNAL_ERROR500Unexpected server failure. Report the request ID.
