Data yang tidak kami simpan

  • File gambar yang diunggah — diproses sementara untuk menghasilkan hasil, lalu dihapus setelah pemrosesan selesai.
  • Hasil ekstraksi (misalnya NIK, nama, alamat) — hanya dikembalikan ke browser Anda, tidak disimpan dan tidak dicatat di log.
  • Token akses — diverifikasi di server, tidak pernah dicatat di log.

Keamanan

  • Identitas diverifikasi di server; batas uji coba tidak dapat diubah dari browser.
  • File divalidasi di server sebelum diproses, dengan batas ukuran dan rate limit.
  • Kredensial layanan disimpan di server dan tidak pernah dikirim ke browser.

Ketentuan penggunaan

  • Hanya unggah dokumen yang Anda berwenang untuk memprosesnya.
  • Hasil dibuat oleh mesin, dapat mengandung kesalahan, dan tidak boleh menjadi satu-satunya dasar keputusan penting.
  • Layanan gratis dibatasi rate limit dan dapat dihentikan sementara untuk pemeliharaan.
  • Dilarang menyalahgunakan, membebani, atau mencoba melewati batas uji coba layanan.
