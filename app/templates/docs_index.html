LUTUNG AI API

Integrate LUTUNG AI services into your application over a simple HTTPS + JSON API.

Access in this MVP

Public self-service API keys are not available yet. Endpoints are used by the LUTUNG Playground and require a signed-in LUTUNG session. Pilot developers who need integration access should contact the LUTUNG team.

Base URL & versioning

Base URL
https://<lutung-host>/api/v1

All endpoints are versioned under /api/v1. Breaking changes ship under a new version prefix.
